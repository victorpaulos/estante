Conectar este aparelho

O painel salva as músicas no seu GitHub. Para isso ele precisa de uma chave de acesso, criada uma vez só. Ela fica guardada só neste aparelho.

  1. Abra github.com/settings/personal-access-tokens/new
  2. Token name: estante · Expiration: a mais longa que houver
  3. Repository access: Only select repositories → estante
  4. Permissions → Repository → Contents: Read and write
  5. Clique em Generate token, copie e cole abaixo
